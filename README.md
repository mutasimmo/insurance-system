# 🏥 نظام التأمين الطبي

نظام متكامل لإدارة الكافلين والمكفولين في التأمين الطبي.

## 🚀 التقنيات المستخدمة
- **Backend**: Node.js, Express, SQLite, JWT
- **Frontend**: React, Axios, React Icons
- **النشر**: Vercel (Frontend), Render (Backend)

## 📦 التثبيت والتشغيل المحلي

### 1. تشغيل الباكند
```bash
cd backend
npm install
npm run dev
